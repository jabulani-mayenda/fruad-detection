About The Project

Catching Fraud Before
It Catches You

This project builds a binary classification system that distinguishes legitimate credit card transactions from fraudulent ones — addressing one of the most challenging problems in financial security: extreme class imbalance.

⚡ The dataset contains transactions made by European cardholders in September 2013. Only 0.172% of all transactions are fraud, making this a severely imbalanced classification problem.

Objectives

What This Project Aims To Do

Four core goals drive every decision in this project — from data preprocessing to model selection.

01 / Detect
Identify Fraudulent Transactions
Build a robust binary classifier capable of accurately detecting fraud while minimising false negatives — the most costly type of error.
02 / Balance
Handle Class Imbalance
Apply SMOTE and class weighting techniques to prevent the model from being biased toward the majority class of legitimate transactions.
03 / Compare
Benchmark Two Algorithms
Evaluate Logistic Regression against Random Forest to determine which delivers better precision, recall, F1, and AUC-ROC on this dataset.
04 / Interpret
Produce Actionable Insights
Generate confusion matrices, ROC curves, and feature importance plots to deliver transparent, interpretable model explanations.
